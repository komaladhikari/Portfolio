# Developer Thinking Toolkit

Copy this folder and the sibling `AGENTS.md` into any repository. Start Codex in the repository root.

## How to use
1. Ask Codex: `Read AGENTS.md and developer-toolkit/MASTER_PROMPT.md. Analyze this project before making changes.`
2. For a specific activity, say: `Follow developer-toolkit/prompts/03-compare-approaches.md for [feature]. Do not edit files.`
3. When ready, explicitly approve a small implementation step.
4. Record important decisions in `templates/decision-record.md` and concepts in `templates/learning-notes.md`.

These are guidance files, not executable scripts. Keep repository-specific instructions in the root AGENTS.md. Never copy secrets into notes.
